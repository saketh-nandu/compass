9. HOW TO USE
================================================================================

1. SEND CHAT MESSAGE WITH MEDIA:
   - Open chat screen
   - Tap + button
   - Select image/video/file
   - Media uploads automatically
   - Message appears in chat

2. SEND NOTIFICATION:
   - Open chat screen
   - Tap "Notify Partner" button
   - Notification sent to all partner devices
   - Shows as compass update
   - 5-minute cooldown before next notification

3. RECORD AUDIO/VIDEO:
   - Open recordings tab
   - Tap record button
   - Record audio/video
   - Stop and save
   - Recording uploads automatically

4. SAVE TO MEMORIES:
   - Long press message in chat
   - Select "Save to Memories"
   - Message saved with timestamp
   - Searchable and categorizable
