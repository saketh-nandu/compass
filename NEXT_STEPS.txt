================================================================================
TROUBLESHOOTING
================================================================================

If users don't appear:
  1. Check users created in auth.users table
  2. Verify user profiles in users table
  3. Check RLS policies allow access

If login fails:
  1. Verify email matches exactly
  2. Check password is correct
  3. Ensure user is auto-confirmed

If realtime doesn't work:
  1. Verify realtime enabled in dashboard
  2. Check tables in supabase_realtime publication
  3. Check anon key permissions
